# Contributor agent instructions

- Work inside this repository. Do not inspect unrelated personal folders or global credentials.
- The user runs and restarts servers. Run appropriate tests; do not start services.
- Read README.md and docs/IMPLEMENTATION_STATUS.md before changing runtime behavior.
- Generate temporary test data in fixtures. Keep research workspaces local.
- Keep private research workspaces, source archives, keys, and generated reports out of Git.
- Never convert a source argument or user interpretation into a verified finding without evidence.
- Keep expert contexts independent and retrieval bounded. Never silently enable a model or cloud service.
- Run Ruff and relevant tests after code changes. Do not push or publish without explicit authorization.

This is a portable example. The owner's existing AGENTS.md remains local because it contains personal filesystem restrictions.
