# GitHub sharing boundary

The shared checkout contains the framework, tests, setup docs, CI, and a blank environment template. Tests generate temporary data.

Keep research workspaces, charters, notes, transcripts, credentials, and run output in ignored locations. Before each push, review the staged file list and confirm that the source archive and CI work from a checkout with only the shared files. See [source management](SOURCES.md) and [development checks](DEVELOPMENT.md).
